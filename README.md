# Portfólio | Bruna Baffile

Site pessoal feito com HTML, CSS e JavaScript, pronto para publicação no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: menu mobile e ano automático no rodapé.

## Antes de publicar
1. No `index.html`, substitua `SEUEMAIL@EXEMPLO.COM` pelo e-mail profissional.
2. Substitua `SEU-USUARIO` nos links do LinkedIn e GitHub.
3. Revise o período da experiência na Tury e todas as descrições.
4. Confirme se deseja manter Power BI na lista de ferramentas, de acordo com seu nível de domínio.
5. Envie uma foto profissional para substituir o espaço reservado no topo do site. Quando a foto for enviada, salve-a como `foto-bruna.jpg` dentro de uma pasta `assets` e atualize o HTML/CSS conforme necessário.
6. Adicione somente projetos, imagens e documentos que você tenha autorização para divulgar.

## Publicar com GitHub Pages
1. Crie um repositório público chamado `portfolio`.
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço normalmente será `https://SEU-USUARIO.github.io/portfolio/`.

O GitHub Pages pode levar alguns minutos para publicar a primeira versão.
